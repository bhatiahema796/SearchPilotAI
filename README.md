\# SearchPilot AI

\### SEO \& AEO Automation Agency



\## 1. Project Overview



SearchPilot AI is a custom Python-based AI agency that automates SEO and Answer Engine Optimization (AEO) tasks using eight specialized AI employees.



A Project Manager coordinates employee tasks, while a Quality Auditor reviews their reports before approval.



\## 2. AI Employees



1\. Project Manager

2\. Keyword Researcher

3\. SEO Content Writer

4\. Technical SEO Auditor

5\. AEO Specialist

6\. Competitor Analyst

7\. Performance Analyst

8\. Quality Auditor



\## 3. Main Features



\- AI-powered employee task execution.

\- Automated task assignment and coordination.

\- Quality review and revision workflow.

\- Employee activity logging.

\- Google Sheets activity tracking.

\- Automated Gmail daily performance reports.

\- Streamlit management dashboard.

\- Local JSON task and activity records.



\## 4. Technology Stack



\- Python

\- Streamlit

\- OpenRouter API

\- Google Sheets API

\- Gmail SMTP

\- JSON

\- Git and GitHub



\## 5. Project Structure



\- `main.py` - Main application entry point.

\- `employees/` - Employee instructions and workflows.

\- `shared/` - AI engine, task manager and employee runner.

\- `dashboard/` - Streamlit dashboard.

\- `integrations/` - Google Sheets and Gmail integrations.

\- `config/` - Agency configuration.

\- `data/` - Task records and history.

\- `logs/` - Employee activity logs.

\- `reports/` - Employee reports and quality reviews.

\- `.installed.json` - Custom project installation manifest.

\- `requirements.txt` - Python dependencies.

\- `.env.example` - Environment variable template.
