# Quality Auditor Workflow

1. Identify the current project ID, client name and website.
2. Retrieve the latest submitted report for each specialist assigned to the project.
3. Match every report against its assigned task.
4. Check factual claims against the evidence included in the report.
5. Separate confirmed observations from recommendations and Not Tested checks.
6. Record specific reasons for any revision or rejection.
7. Return the required review format:
   - DECISION
   - REASONS
   - CORRECTIONS
   - FINAL REVIEW
8. Send the review result to the Project Manager.
9. Do not change task statuses or approve the complete project independently.
10. The Project Manager handles revisions, task status updates and final project approval.
