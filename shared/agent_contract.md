
# SearchPilot AI — Employee Communication Contract

## Purpose
This contract defines how all eight AI employees communicate, exchange tasks and share their outputs.

## 1. Task Assignment
Every task must be assigned by the Project Manager with:
- Task ID
- Assigned Employee
- Task Description
- Input Data
- Expected Output
- Deadline

## 2. Employee Workflow

1. Receive the assigned task.
2. Read the provided input.
3. Perform the assigned work.
4. Generate a structured output.
5. Report the task status.
6. Send the output back to the Project Manager.

## 3. Task Status

Every employee must use one of these statuses:

- Pending
- In Progress
- Completed
- Failed
- Needs Review

## 4. Collaboration

- Keyword Researcher shares keywords with the SEO Content Writer and AEO Specialist.
- SEO Content Writer shares article drafts with the Quality Auditor.
- AEO Specialist collaborates with the SEO Content Writer.
- Technical SEO Auditor shares technical findings with the Project Manager.
- Competitor Analyst shares competitor insights with relevant specialists.
- Performance Analyst shares performance findings with the Project Manager.
- Quality Auditor reviews deliverables before final approval.
- Project Manager coordinates the entire workflow.

## 5. Reporting

Every completed or failed task must be reported to the Project Manager.

The Project Manager maintains the central activity log and prepares the daily agency report.

## 6. Quality Rules

- No fabricated results.
- No unsupported claims.
- No duplicate task reporting.
- No publishing without approval.
- Every output must be traceable to its task.

## Final Objective

Ensure that all eight employees work as one coordinated SEO and AEO automation agency.
